# ADR-001: Build a Resume Analyzer using Deterministic Logic and Gemini 1.5 Pro

Date: 9/22/2026  Status: accepted

## Context
The CEN 5064 software design project requires building a complete and testable system within one semester as a solo developer. 
The system needs to analyze resumes against job descriptions, but passing entire documents to an LLM for simple counting is slow, untestable, and violates the separation of business rules from external machinery.

## Decision
We will build a React/Next.js frontend and a Python (FastAPI/Flask) backend. We are strictly separating deterministic domain logic from generative AI. 
- Exact keyword overlap, section extraction, and flagging unquantified metrics will run entirely via custom Python domain rules (no AI).
- Gemini 1.5 Pro (via Google AI Studio) will only be invoked for high-level generative tasks, specifically rewriting the flagged bullets and drafting the cover letter.

## Consequences
- **Positive:** Domain logic (ATS scoring) is highly cohesive, decoupled from external APIs, and 100% testable using standard unit tests.
- **Positive:** Reduces API latency and cost by limiting Gemini calls to strictly generative tasks.
- **Negative:** Requires managing a multi-container stack (Node.js frontend and Python backend) for a solo developer.
